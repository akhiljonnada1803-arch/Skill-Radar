01. Architecture Overview

KERNEL / VM

Standard LLM inference traditionally wastes between 60% and 80% of accelerator VRAM through rigid, contiguous static memory allocations for request key-value (KV) caches. PagedAttention transposes classic operating system virtual memory paging into GPU kernel execution, dividing sequential attention tokens into non-contiguous physical memory blocks. This mechanical decoupling reduces dynamic internal allocation overhead to near-zero and permits immediate cross-request page sharing.

02. Practical Applications

3 USE CASES
Application A

Multi-Tenant High-Density Serving

Enables dynamic continuous request batching without pre-allocating worst-case sequence buffers, saturating hardware capacity.

Application B

Speculative & Parallel Sampling

Shares prefix prompt KV-cache references simultaneously across multiple candidates without copying memory pages.

Application C

Constrained Hardware Deployments

Runs dense 70B parameter models on unified memory workstations and edge setups with minimal allocation headroom.

03. Core Impact

INFRASTRUCTURE

By removing physical memory fragmentation, PagedAttention delivers a 2× to 4× throughput multiplier without requiring model parameter reduction or quantization loss. It has established non-contiguous memory management as the de facto standard across open-source and enterprise inference infrastructure.
